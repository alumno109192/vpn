# Changelog

Todos los cambios importantes de este proyecto se documentarán en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere al [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-07-30

### Added
- Aplicación inicial con interfaz gráfica PyQt5
- Soporte para OpenVPN y StrongSwan/IPSec
- Sistema de licencias con período de prueba
- Actualizaciones automáticas
- Gestión de múltiples conexiones VPN
- Monitoreo en tiempo real del estado de conexión
- Scripts de build para macOS, Linux y Windows
- Configuración mediante diálogos gráficos
- Sistema de logs integrado
- Soporte multiplataforma (macOS, Linux, Windows)

### Security
- Encriptación de licencias
- Validación offline de licencias
- Almacenamiento seguro de configuraciones

## Tipos de cambios
- `Added` para nuevas funcionalidades
- `Changed` para cambios en funcionalidades existentes
- `Deprecated` para funcionalidades que se eliminarán pronto
- `Removed` para funcionalidades eliminadas
- `Fixed` para corrección de bugs
- `Security` para cambios relacionados con seguridad
